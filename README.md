## Part A: HTML Tasks
- **index.html**: This file displays my basic information, ALT School ID, biography, reasons for joining, and goals. As instructed, it also includes a fragment identifier ('Back to Top' link) and also makes use of an accessible accordion component.
- **form.html**: This mirrors the AltSchool Sign In page.  
Both of the pages include a navigation bar linking `index.html` and `form.html`.

---

## 🧑‍💻 Part B: JavaScript Tasks
These 5 tasks are solved in separate files put into one folder named **Part B.** This is what each of the file contains
- **Problem 1 (deepEqual.js)**: This performs a deep equality check between objects.  
- **Problem 2 (objectDiff.js)**: This contains an object difference finder solution.  
- **Problem 3 (deepFreeze.js)**: Deep freeze utility to make objects immutable.  
- **Problem 4 (privateCounterFactory.js)**: This solves the Private Counter Factory problem.  
- **Problem 5 (schemaValidator.js)**: Schema validator that checks object properties and types.

---

- Open 'index.html' in a browser to view Part A. Click on 'Registration Form' to access **form.html**.

  ```bash
  node solutions/deepEqual.js
